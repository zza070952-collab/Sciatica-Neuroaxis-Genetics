# Computational workflow accompanying the sciatica TXNL1 manuscript

Frozen computational chain: QC, LDSC, MAGMA, five-tissue FUSION, conditional/joint analysis, full-cis ABF/SuSiE colocalization, adult lumbar-spinal gsMap, spinal/DRG reference localization, corrected DRG recurrence, locked candidate integration and computational figure generation.

Large and license-restricted third-party data are not redistributed. Wet-laboratory raw data and statistical scripts are excluded. Exact Methods/Figure mappings and source-script SHA256 provenance are provided.

The smoke test verifies code/configuration structure and executes core aggregation functions; it is not a full-data rerun. Retained inherited-input and figure-provenance gaps are explicitly documented in `docs/reproducibility_limitations.md`. No archival DOI has been minted.
